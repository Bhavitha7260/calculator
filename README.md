**Simple Calculator Using Python**

Description

The Simple Calculator is a beginner-friendly Python project that performs basic arithmetic operations. It allows users to enter two numbers and select an operation to calculate the result.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Simple and easy-to-use interface

Technologies Used

- Programming Language: Python
- IDE: Visual Studio Code

How to Run

1. Install Python on your computer.

2. Open the project in Visual Studio Code.

3. Create a file named "calculator.py".

4. Write the calculator program and save it.

5. Run the program using the terminal:
   
   python calculator.py

Example Output

Enter first number: 10
Enter second number: 5
Choose operation (+, -, *, /): +
Result: 15

Learning Outcomes

- Understanding Python basics
- Using conditional statements
- Performing arithmetic operations
- Taking user input and displaying output

Conclusion

This project demonstrates the basic concepts of Python programming through a simple calculator. It is useful for beginners to practice input, operators, and conditional statements.
